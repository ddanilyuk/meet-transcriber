# Meet Transcriber

Локальне Chrome-розширення для Google Meet, яке зберігає субтитри мітингів (українською) разом з іменами мовців.

- Читає вбудовані субтитри Google Meet зі сторінки (без API і без зовнішніх серверів).
- Показує транскрипт у сайдбарі в стилі Meet; рідний оверлей субтитрів прихований, але його можна ввімкнути.
- Зберігає все локально (`chrome.storage.local`), має архів мітингів і експорт у Markdown / TXT / JSON.

> Документація з встановлення з'явиться, коли розширення буде готове.
